# Web 手动同步交互说明

## 页面入口

页面名称为“视觉页面中心多表同步”。首页只显示：

- 同步按钮
- 最近一次同步情况
- 配置和规则按钮

打开页面、刷新页面或到达某个时间点都不会自动执行同步，也不会读取在线表格。首页不提供预览或测试按钮。

## 手动同步

1. 用户点击“同步”。
2. 浏览器提示本次操作会读取 10 张分表并写入固定总表。
3. 用户确认后，页面立即显示“同步中... 已完成 0%”。
4. 后端依次读取总表和 10 张分表、汇总数据并写入总表。
5. 页面每 500 毫秒读取一次任务状态，并显示后端上报的真实完成百分比。
6. 同步完成后，页面用最新结果替换进度信息。

同步期间按钮不可重复点击。分表始终只读。

## 进度口径

一次任务按 `分表数 + 3` 个步骤计算：

1. 读取总表
2. 逐张读取分表，每张完成后增加一个步骤
3. 汇总和冲突判断
4. 写入总表或确认没有需要写入的数据

当前固定 10 张分表，因此共 13 个步骤。单张表读取和最终写入期间，百分比可能短暂停留；这表示当前步骤尚未完成，并非页面卡住。

## 最近一次同步情况

任务完成后逐行显示：

```text
同步时间：2026-07-28 14:30:05；
10/10 张分表同步成功；
同步失败分表：无；
更新总表 12 行；
更新 25 个单元格；
3 个分表货号在总表中不存在，按规则未新增；
2 个冲突货号；
耗时约 1 分 8 秒；
```

存在读取或解析失败的分表时，“同步失败分表”一行使用顿号列出名称。没有失败分表时显示“无”。存在冲突货号时，冲突数量后显示“点击查看冲突货号”按钮；点击后弹窗按行展示冲突货号及其出现过的全部分表。

## 配置和规则弹窗

点击“配置和规则”后，以弹窗展示计划名称、固定总表、分表数量、字段映射、10 张分表和全部同步规则。关闭弹窗不会触发同步。

## 验收场景

1. 页面打开时不会执行同步。
2. 首页没有预览或测试按钮。
3. 取消确认框后不会读取或写入表格。
4. 同步期间显示百分比并禁止重复点击。
5. 分表非空字段能够覆盖总表。
6. 分表空白字段能够清空总表对应字段。
7. 分表完全不存在的货号不会清空总表旧值。
8. 空白与非空的跨分表差异会标记为冲突。
9. 分表货号不在总表时不会自动新增行。
10. 单张分表读取失败时，其他成功分表仍允许写入。
11. 冲突货号明细弹窗逐行列出货号和全部相关分表，重复分表名称只显示一次。
